# Як здавати домашки

## Гілки

Кожна домашка є на окремій гілці. Щоб почати роботу спочатку потрібно перемкнутись на потрібну гілку і з неї створити свою гілку з назвою `{name}/{hw}`, для прикладу була гілка `01-hw`, потрібно з неї створити `oleh/01-hw`. В кожній гілці буде інструкція до виконання домашки.

## Пул реквести

Потрібно на github створити пул реквест зі своєї гілки в гілку з домашкою з якої створювалась ваша гілка, для прикладу `01-hw` <- `oleh/01-hw`. В поле assignee потрібно поставити себе а в reviewers вашого викладача. Після апруву пул реквеста домашка вважається зданою, після реджекту потрібно проглянути коментарі викладача в пул реквесті і виправити помилки та запушити коміти в ту ж гілку.

# API

## Додати можливість створення нового поста

1. Створити сторінку `create-post.view` для створення нового поста `/create-post`
2. Створити компонент `create-post-form` з формою для створення нового поста
3. Прописати валідаційну схему за допомогою `zod` та обробити форму за допомогою `react-hook-form`
4. При сабміті форми зробити запит на апі для створення нового поста за допомогою `@tanstack/react-query`
5. Після успішного виконання запиту перенести користувача на сторінку всіх постів

## Обробка завантаження та помилок

- Під час завантаження запиту на створення поста відключити кнопку створення поста і всі інпути
- Якщо станеться помилка при запиті відображати `Alert` компонент з текстом помилки
